# ClassPilot — School ERP starter

A responsive, single-page school management portal prototype inspired by the attached blue-and-white ERP reference. It includes a dashboard plus student directory, daily attendance, fee tracking, academic notes, and school announcements.

## Run it

Open `index.html` in a modern browser. No build step or external dependencies are required.

## Included interactions

- Add students to the directory.
- Record fee payments and update balances.
- Mark attendance and toggle a student's daily status.
- Publish school announcements and save academic notes.
- Search the student list, export it as CSV, and navigate between portal sections.
- Demo changes are stored in the browser's `localStorage`.

## Important

This is a front-end demonstration, not production-ready student information software. Data is only stored in the current browser and is not shared with other users or devices. Before using real student data, add a secure backend, authentication and role-based permissions, encrypted transport and storage, backups, audit trails, validated workflows, and compliance review for applicable student privacy laws. It does not provide online payment processing or messaging delivery.
